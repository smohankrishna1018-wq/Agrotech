# 🌱 AgroSense - Smart Agriculture Management System

AgroSense is a modern smart agriculture website developed using HTML, CSS, and JavaScript. It helps farmers make informed decisions by providing crop information, weather forecasts, irrigation planning, and AI-inspired disease detection in one easy-to-use platform.

---

## 🚀 Features

- 🔐 Login & Registration
- 📊 Interactive Dashboard
- 🌾 Crop Information
- 🌦 Weather Dashboard
- 💧 Smart Irrigation Calculator
- 🤖 AI Plant Disease Detection Interface
- 📱 Responsive Design
- 🌙 Premium Black Theme
- 📈 Charts & Statistics
- 📍 Contact & About Pages
- 🚀 GitHub Pages Ready

## 📥 Installation

1. Download or clone the repository.

```bash
git clone https://github.com/yourusername/AgroSense.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

---

## 🌐 Deploy on GitHub Pages

1. Upload the project to GitHub.
2. Open **Repository Settings**.
3. Select **Pages**.
4. Choose:

```
Deploy from Branch
```

5. Select:

```
Branch: main
Folder: /root
```

6. Click **Save**.

Your website will be live in a few minutes.
